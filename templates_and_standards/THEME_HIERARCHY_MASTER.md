## 一、主题分类体系总览

### 1.1 五大层次框架

项目采用**5大层次**的知识体系结构，每个层次对应一个主要的文档目录：

| 层次代码 | 层次名称 | 英文名称 | 对应目录 | 主要内容 |
|---------|---------|---------|---------|---------|
| **FL** | 基础理论层 | Foundation Layer | docs/01-foundations/ | 形式化基础、数学模型、语义模型等 |
| **CML** | 核心模型层 | Core Model Layer | docs/02-project-management/ | 生命周期、资源、风险、质量模型 |
| **VL** | 验证理论层 | Verification Layer | docs/03-formal-verification/ | 模型检验、定理证明、一致性检查 |
| **AL** | 应用模型层 | Application Layer | docs/04-industry-applications/ | 行业应用、技术应用、专业领域模型 |
| **IL** | 实现验证层 | Implementation Layer | docs/05-implementations/ | Rust、Haskell、Lean实现 |

### 1.2 主题层次结构统计

- **一级主题**: 5个层次
- **二级主题**: 30+个主要主题
- **三级主题**: 150+个细分主题
- **概念层次**: 基础概念、核心模型、形式化定义
- **模型层次**: 理论模型、应用模型、实现模型

## 四、主题标签规范

### 4.1 主题标签格式

主题标签采用以下格式：

```
[层次代码]-[二级主题编号].[三级主题编号].[四级主题编号]
```

例如：

- `FL-1.1-1.1.1` 表示基础理论层-形式化基础理论-项目定义与形式化规范-项目四元组定义
- `CML-2.1-2.1.1` 表示核心模型层-项目生命周期模型-启动阶段-项目章程
- `VL-3.1-3.1.1` 表示验证理论层-形式化验证理论-模型检验-状态空间搜索
- `AL-4.1-4.1.1` 表示应用模型层-软件开发模型-敏捷开发模型-Scrum
- `IL-5.1-5.1.1` 表示实现验证层-Rust实现-项目状态转换系统

### 4.2 层次代码

- **FL**: Foundation Layer (基础理论层)
- **CML**: Core Model Layer (核心模型层)
- **VL**: Verification Layer (验证理论层)
- **AL**: Application Layer (应用模型层)
- **IL**: Implementation Layer (实现验证层)
