## 📈 Network Structure / 网络结构

### Axiom Types / 公理类型

1. **Existence Axioms** (存在性公理): Guarantee existence of structures
2. **Uniqueness Axioms** (唯一性公理): Specify conditions for uniqueness
3. **Preservation Axioms** (保持性公理): State what properties are preserved
4. **Universal Axioms** (泛性公理): Describe universal properties

### Theorem Types / 定理类型

1. **Existence Theorems** (存在性定理): Prove structures exist
2. **Uniqueness Theorems** (唯一性定理): Prove structures are unique
3. **Characterization Theorems** (刻画定理): Characterize structures
4. **Relationship Theorems** (关系定理): Connect different concepts

## 🔍 How to Read Networks / 如何阅读网络

### Reading Direction / 阅读方向

- **Top to Bottom**: Axioms → Theorems → Applications
- **Left to Right**: General → Specific
- **Arrows**: Logical dependency (A → B means A is used to prove B)

### Color Coding / 颜色编码

- **Blue** (蓝色): Axioms / 公理
- **Yellow** (黄色): Theorems / 定理
- **Green** (绿色): Applications / 应用
