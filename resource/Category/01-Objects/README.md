# Objects / 对象

## 📋 Overview / 概述

This directory contains **Formal-ProgramManage** project management concepts organized as **objects** in various categories.

本目录包含作为各种范畴中的**对象**组织的**Formal-ProgramManage**项目管理概念。

## 🔗 与 docs 的层、转换对应 / Layer and Transformation

- **对象**：对应各层的实体（项目、生命周期、资源、风险、质量、验证、类型、控制流、数据流、执行等）
- **与层对应**：基础理论层（Project、Mathematical、Semantic）→ 核心模型层（Lifecycle、Resource、Risk、Quality）→ 验证理论层（Verification、Type、Control/Data/Execution）→ 应用模型层（Industry Application、Software、Engineering、Business、AI、Healthcare）
