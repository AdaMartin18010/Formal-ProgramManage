# Transfer 变换目录索引

## 概述

本索引按 **Formal-ProgramManage** 项目**转换（变换）**与 `docs/` 的对应编排。微积分变换等已归档至 `_archive/`，此处仅列项目管理向框架。

## 与 docs 的转换对应

- **生命周期转换** $\delta$、转换点 $T$（lifecycle-models）→ **02-变换类型框架**、**03-变换关系网络框架**（变换路径）
- **状态转换** $\rightarrow$（01-foundations）→ **01-等价关系框架**（结构/行为等价）、**03-变换关系网络**
- **层次转换** L1→…→L5（KNOWLEDGE_NETWORK）→ **02–03**、**04-综合应用**、**07-行业应用**
- **模型/等价转换**（06-ci-verification）→ **01-等价关系框架**
