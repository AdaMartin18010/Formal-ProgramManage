## 2. Definition / 定义

### 2.1 Optimization Transformation Definition / 优化变换定义

**Definition 2.1** (Project Optimization Transformation)

A project optimization transformation $Optimize: P_1 \to P_2$:

$$Optimize(P_1) = P_2 \text{ and } Objective(P_2) \geq Objective(P_1)$$

improves objective function.

### 2.2 Framework Definition / 框架定义

**Definition 2.2** (Optimization Framework)

The optimization framework is:

$$OptimizeFramework = \{Optimize, Objective, Constraint, Improve\}$$

with optimization function, objective function, constraints, and improvement.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Optimization as Functor / 优化作为函子

**Definition 3.1** (Optimization Functor)

Optimization is a functor:

$$Optimize: \mathbf{Project} \to \mathbf{Project}$$

improving objectives.

### 3.2 Framework Properties / 框架性质

**Axiom 3.1** (Optimization Improvement)

Optimization improves objectives:

$$\forall Optimize: Objective(Optimize(P)) \geq Objective(P)$$

### 9.2 应用案例 / Application Case

**Case 9.2** (关键路径压缩与资源平滑 / Critical Path Crashing and Resource Leveling)

某基建项目通过关键路径上赶工与资源再分配，在预算上浮 5% 的约束下将工期由 24 个月减至 20 个月。本框架将此类变换视为优化态射 $Opt: P \to P'$，在满足 $Objective(P') \succ Objective(P)$（如工期更短）下调整资源与时间参数。参见 [13-综合实践概念/03-项目管理案例分析](../../Concept/13-综合实践概念/03-项目管理案例分析.md)。
