## 2. Definition / 定义

### 2.1 Transformation Graph Definition / 变换图定义

**Definition 2.1** (Project Transformation Graph)

A project transformation graph is:

$$G = (V, E)$$

where $V$ are projects and $E$ are transformations.

### 2.2 Framework Definition / 框架定义

**Definition 2.2** (Transformation Graph Framework)

The transformation graph framework is:

$$GraphFramework = \{G, Path, Analysis, Structure\}$$

with graph, paths, analysis, and structure.

---

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Graph as Category / 图作为范畴

**Definition 3.1** (Transformation Graph Category)

The transformation graph category $\mathbf{TransGraph}$ consists of:

- **Objects / 对象**: Projects $P \in V$
- **Morphisms / 态射**: Transformations $T: P_1 \to P_2 \in E$

### 3.2 Framework Properties / 框架性质

**Axiom 3.1** (Graph Category Axioms)

Graph category satisfies category axioms:

- **Composition / 复合**: Path composition / 路径复合
- **Identity / 恒等**: Identity transformations / 恒等变换

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Graph Connectivity)

Graph is connected:

$$\forall P_1, P_2: \exists Path(P_1, P_2)$$

**Property 4.2** (Path Composition)

Paths compose:

$$\forall Path_1, Path_2: Path_1 \circ Path_2 = Path_3$$

---

## 5. Relations / 关系

### 5.1 Relations to Other Concepts / 与其他概念的关系

**Relation 5.1** (Graph → Project)

Graph contains projects:

$$Project: \mathbf{TransGraph} \to \mathbf{Project}$$

**Relation 5.2** (Graph → Transformation)

Graph contains transformations:

$$Transformation: \mathbf{TransGraph} \to \mathbf{Transformation}$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Network" Metaphor)

Transformation graph is like network:

- **Nodes / 节点**: Projects / 项目
- **Edges / 边**: Transformations / 变换
- **Paths / 路径**: Transformation paths / 变换路径

---

## 8. Argumentation / 论证

### 8.1 Why Transformation Graphs Exist / 为什么变换图存在

**Argument 8.1** (Relationship Argument)

Transformation graphs exist because:

1. Transformations have relationships
2. Relationships form graphs
3. Graphs enable analysis
4. Analysis enables management

## 9. Applications / 应用

### 9.1 Project Management Applications / 项目管理应用

- **Path Finding**: Finding transformation paths
- **Graph Analysis**: Analyzing transformation graphs
- **Network Optimization**: Optimizing transformation networks
- **Relationship Management**: Managing transformation relationships

### 9.2 应用案例 / Application Case

**Case 9.2** (组合内项目演进的变换图 / Transformation Graph of Portfolio Evolution)

某产品组合以项目为顶点、阶段推进与重构为边，构成有向图 $G = (V, E)$。从「概念验证 $P_0$」到「量产 $P_n$」存在多条路径（如 重构→优化 或 优化→重组→优化），通过图分析比较路径的成本与风险，支撑组合决策。参见 [13-综合实践概念/03-项目管理案例分析](../../Concept/13-综合实践概念/03-项目管理案例分析.md)。
