## 2. Definition / 定义

### 2.1 Engineering PM Application Definition / 工程项目管理应用定义

**Definition 2.1** (Engineering Project Management Application)

An engineering project management application applies:

$$EngineeringPMApp: \mathbf{EngineeringProject} \times \mathbf{EngineeringPractices} \to \mathbf{Result}$$

engineering practices to engineering projects.

### 2.2 Framework Definition / 框架定义

**Definition 2.2** (Engineering PM Application Framework)

The engineering PM application framework is:

$$EngineeringPMFramework = \{Design, Manufacturing, Quality, Standards\}$$

with design, manufacturing, quality, and standards.

### 3.1 Engineering PM Application as Functor / 工程项目管理应用作为函子

**Definition 3.1** (Engineering PM Application Functor)

Engineering PM application is a functor:

$$EngineeringPMApp: \mathbf{EngineeringProject} \times \mathbf{EngineeringPractices} \to \mathbf{Result}$$

### 9.2 应用案例 / Application Case

**Case 9.2** (EPC 总包的阶段门与设计—采购—施工耦合 / EPC Stage Gates and D–P–C Coupling)

某 EPC 项目在详细设计 30% 时启动长周期设备采购，在 70% 时准许现场开工；本框架将 D–P–C 建模为态射链 $\tau_{D} \to \tau_{P} \to \tau_{C}$，阶段门 $C(State, \%)$ 控制 $\tau$ 的触发条件，避免返工与工期膨胀。参见 [08-行业应用概念/02-工程项目管理](../../Concept/08-行业应用概念/02-工程项目管理.md)。
