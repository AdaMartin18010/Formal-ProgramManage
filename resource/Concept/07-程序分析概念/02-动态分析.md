## 2. Definition / 定义

### 2.1 Nielson Definition / Nielson 定义

**Definition 2.1** (Dynamic Analysis - Nielson)

Dynamic analysis analyzes programs during execution:

$$DynamicAnalysis: \mathbf{Program} \times \mathbf{Execution} \to \mathbf{AnalysisResult}$$

**Analysis Types / 分析类型**:

- **Profiling / 性能分析**: Performance profiling
- **Tracing / 跟踪**: Execution tracing
- **Monitoring / 监控**: Runtime monitoring

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Dynamic Analysis - Formal Definition)

Dynamic analysis is a function:

$$DynamicAnalysis: \mathbf{Program} \times \mathbf{Execution} \to \mathbf{AnalysisResult}$$

where $\mathbf{Execution}$ is execution trace.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Dynamic Analysis as Functor / 动态分析作为函子

**Definition 3.1** (Dynamic Analysis Functor)

Dynamic analysis is a functor:

$$DynamicAnalysis: \mathbf{Program} \times \mathbf{Exec} \to \mathbf{DynamicAnalysis}$$

mapping programs and executions to analysis results.

### 3.2 Dynamic Analysis Properties / 动态分析性质

**Axiom 3.1** (Dynamic Analysis Functoriality)

Dynamic analysis preserves composition:

$$DynamicAnalysis(f \circ g, exec) = DynamicAnalysis(f, exec) \circ DynamicAnalysis(g, exec)$$

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Dynamic Analysis Accuracy)

Dynamic analysis is accurate:

$$\text{observed property} \Rightarrow \text{actual property}$$

**Property 4.2** (Dynamic Analysis Coverage)

Dynamic analysis may have limited coverage:

$$\text{not observed} \not\Rightarrow \text{not exists}$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Runtime Observation" Metaphor)

Dynamic analysis is like runtime observation:

- **Observation / 观察**: Observing program execution / 观察程序执行
- **Measurement / 测量**: Measuring properties / 测量性质
- **Tracking / 跟踪**: Tracking execution / 跟踪执行

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Runtime Observation 配例)

按 7.1「Runtime Observation」比喻：观察如运行中监测、测量如性能与进度、跟踪如执行轨迹。例如 $Monitor(Project)=\{\text{progress}: 50\%, \text{risks}: 3, \text{quality}: \text{good}\}$：动态分析在运行时的观察—测量—跟踪与 7.1 三要素对应，$ProgramAnalysis: \mathbf{StaticAnalysis} \to \mathbf{ProgramAnalysis}$ 体现与静态分析的互补。

4. Dynamic analysis enables monitoring
