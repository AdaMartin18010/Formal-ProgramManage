## 1. Overview / 概述

**English / 英文**:

ISO 21502:2020 provides guidance on project management, replacing ISO 21500:2012. Published in December 2020, it represents a shift from process-based to practice-based approach, applicable to any organization and any type of project. It supports various delivery methods including predictive, incremental, iterative, adaptive, hybrid, and agile approaches.

**中文**:

ISO 21502:2020提供项目管理指南，取代ISO 21500:2012。2020年12月发布，它代表了从基于过程到基于实践的方法转变，适用于任何组织和任何类型的项目。它支持各种交付方法，包括预测性、增量、迭代、自适应、混合和敏捷方法。

**Key Insights / 关键洞察**:

- **Practice-Based / 基于实践**: Focus on practices rather than processes / 关注实践而非过程
- **Universal Applicability / 通用适用性**: Applicable to any organization and project type / 适用于任何组织和项目类型
- **Delivery Method Agnostic / 交付方法无关**: Supports all delivery methods / 支持所有交付方法
- **Integrated Approach / 集成方法**: Integrated project management practices / 集成项目管理实践

## 2. Definition / 定义

### 2.1 ISO 21502:2020定义

**Definition 2.1** (ISO 21502:2020)

ISO 21502:2020 is an international standard providing guidance on project management, applicable to any organization (public, private, or charitable) and any type of project regardless of purpose, delivery approaches, life cycle model, complexity, size, cost, or duration.

**Formal Definition / 形式化定义**:

$$\text{ISO21502}: \mathbf{Organization} \times \mathbf{Project} \to \mathbf{Guidance}$$

where guidance is provided for project management in any context.

**Key Characteristics / 关键特征**:

- **Practice-Based / 基于实践**: Focus on practices, not prescriptive processes
- **Universal / 通用**: Applicable to all organizations and projects
- **Flexible / 灵活**: Supports all delivery methods
- **Integrated / 集成**: Integrated project management approach

### 2.2 项目管理概念和指南

**Definition 2.2** (Project Management Concepts and Guidelines)

ISO 21502:2020 provides:

1. **General Concepts / 一般概念**: Core project management concepts
2. **Guidelines / 指南**: Best practice guidelines
3. **Framework / 框架**: Project management framework
4. **Practices / 实践**: Integrated project management practices

**Formal Definition / 形式化定义**:

$$\text{Guidance} = (\text{Concepts}, \text{Guidelines}, \text{Framework}, \text{Practices})$$

### 2.3 项目管理先决条件

**Definition 2.3** (Prerequisites for Formalizing Project Management)

ISO 21502:2020 identifies prerequisites:

1. **Organizational Context / 组织上下文**: Understanding organizational context
2. **Capabilities / 能力**: Project management capabilities
3. **Resources / 资源**: Necessary resources
4. **Governance / 治理**: Governance structure

**Formal Definition / 形式化定义**:

$$\text{Prerequisites} = (\text{Context}, \text{Capabilities}, \text{Resources}, \text{Governance})$$

### 2.4 集成项目管理实践

**Definition 2.4** (Integrated Project Management Practices)

ISO 21502:2020 covers integrated practices:

1. **Benefit Management / 效益管理**: Managing project benefits
2. **Scope Management / 范围管理**: Managing project scope
3. **Resource Management / 资源管理**: Managing resources
4. **Cost Management / 成本管理**: Managing costs
5. **Quality Management / 质量管理**: Managing quality

**Formal Definition / 形式化定义**:

$$\text{IntegratedPractices} = (\text{Benefit}, \text{Scope}, \text{Resource}, \text{Cost}, \text{Quality})$$

### 2.5 项目治理框架

**Definition 2.5** (Project Governance Framework)

ISO 21502:2020 provides governance framework:

$$\text{GovernanceFramework} = (\text{Oversight}, \text{Direction}, \text{Control}, \text{DecisionMaking})$$

where governance includes oversight, direction, control, and decision-making.

### 2.6 项目交付管理

**Definition 2.6** (Project Delivery Management)

ISO 21502:2020 covers delivery management:

$$\text{DeliveryManagement} = (\text{Planning}, \text{Execution}, \text{Monitoring}, \text{Control}, \text{Closure})$$

supporting all delivery methods (predictive, agile, hybrid).

## 3. Category Theory Perspective / 范畴论视角

### 3.1 项目管理实践作为对象

**Definition 3.1** (Project Management Practice Object)

A practice $P \in \mathbf{Practice}$ is an object:

$$P = (\text{Name}, \text{Description}, \text{Context}, \text{Outcomes})$$

where practices are contextual and outcome-oriented.

### 3.2 实践集成作为态射

**Definition 3.2** (Practice Integration Morphism)

Practice integration is a morphism:

$$integrate: P_1 \times P_2 \to P_{integrated}$$

that integrates multiple practices.

### 3.3 项目管理函子

**Definition 3.3** (Project Management Functor)

ISO 21502:2020 corresponds to a functor:

$$ISO21502: \mathbf{Organization} \to \mathbf{ProjectManagement}$$

that provides project management guidance.

## 4. Properties / 性质

### 4.1 实践的完整性

**Property 4.1** (Practice Completeness)

ISO 21502:2020 provides complete coverage:

$$\bigcup_{P \in \text{Practices}} \text{Domain}(P) = \mathbf{ProjectManagement}$$

### 4.2 实践的适应性

**Property 4.2** (Practice Adaptability)

Practices are adaptable:

$$\text{Adapt}(P, \text{Context}) = P'$$

where practices adapt to different contexts.

### 4.3 实践的有效性

**Property 4.3** (Practice Effectiveness)

Practices are effective:

$$\text{Effectiveness}(P) = f(\text{Outcomes}(P))$$

where practices produce desired outcomes.

## 📊 Summary / 总结

ISO 21502:2020 provides comprehensive guidance on project management, applicable to any organization and project type. It represents a practice-based approach that supports all delivery methods, providing integrated project management practices and governance framework.

ISO 21502:2020提供项目管理的综合指南，适用于任何组织和项目类型。它代表了一种基于实践的方法，支持所有交付方法，提供集成的项目管理实践和治理框架。
