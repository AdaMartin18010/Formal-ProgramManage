## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Project Constraints - PMBOK 7th Edition)

Project constraints are limitations or restrictions that affect project execution.

**Common Constraints / 常见约束**:

- **Scope Constraints / 范围约束**: Project scope limitations
- **Schedule Constraints / 进度约束**: Time limitations
- **Cost Constraints / 成本约束**: Budget limitations
- **Quality Constraints / 质量约束**: Quality requirements
- **Resource Constraints / 资源约束**: Resource limitations
- **Risk Constraints / 风险约束**: Risk limitations

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Project Constraints - Formal Definition)

Project constraints are functions:

$$C: State \times Resource \times Time \to \{True, False\}$$

where $C(s, r, t) = True$ if constraints are satisfied.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Constraints as Morphisms / 约束作为态射

**Definition 3.1** (Constraint Satisfaction Morphism)

A constraint satisfaction morphism $C: State \times Resource \times Time \to Bool$:

$$C(s, r, t) = True \text{ if constraints satisfied}$$

### 3.2 Constraint Properties / 约束性质

**Property 3.1** (Constraint Consistency)

Constraints are consistent:

$$\forall s, r, t: C(s, r, t) \in \{True, False\}$$

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Constraint Consistency)

Constraints are consistent:

$$\forall s, r, t: C(s, r, t) \in \{True, False\}$$

**Property 4.2** (Constraint Feasibility)

Constraints are feasible:

$$\exists s, r, t: C(s, r, t) = True$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Boundary" Metaphor)

Constraints are like boundaries:

- **Limits / 限制**: Boundary lines
- **Rules / 规则**: Constraint rules
- **Compliance / 合规**: Staying within boundaries
- **Optimization / 优化**: Best within boundaries

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (约束即边界 + 一例 / Constraints as Boundaries with One Example)

用「边界」比喻：约束=可行域的边界。例如范围—进度—成本三角：$C(s,r,t)=True$ 当 $s \le S_0, r \le R_0, t \le T_0$；或「必须在 Q2 前上线」即 $C(State, Resource, Deadline)=True$ 当 $t \le T_{Q2}$。

## 8. Argumentation / 论证

### 8.1 Why Constraints Exist / 为什么约束存在

Constraints exist because:

2. Limitations create constraints
3. Constraints define boundaries
4. Boundaries enable focus
