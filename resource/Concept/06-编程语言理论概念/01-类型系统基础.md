## 2. Definition / 定义

### 2.1 Harper Definition / Harper 定义

**Definition 2.1** (Type System - Harper)

A type system assigns types to terms. Types classify values and ensure type safety.

**Key Components / 关键组件**:

- **Types / 类型**: Type expressions
- **Terms / 项**: Program terms
- **Type Assignment / 类型分配**: Assigning types to terms
- **Type Checking / 类型检查**: Checking type correctness

### 2.2 Pierce Definition / Pierce 定义

**Definition 2.2** (Type System - Pierce)

Type systems provide type safety by preventing type errors.

### 2.3 Formal Mathematical Definition / 形式化数学定义

**Definition 2.3** (Type System - Formal Definition)

A type system is a function:

$$Type: \mathbf{Term} \to \mathbf{Type}$$

assigning types to terms.

---

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Type System as Functor / 类型系统作为函子

**Definition 3.1** (Type Functor)

The type functor $Type: \mathbf{Term} \to \mathbf{Type}$ maps:

- **Objects / 对象**: Terms $t \in \mathbf{Term}$ to types $Type(t) \in \mathbf{Type}$
- **Morphisms / 态射**: Term morphisms to type morphisms

### 3.2 Type Category / 类型范畴

**Definition 3.2** (Category $\mathbf{Type}$)

The category $\mathbf{Type}$ consists of:

- **Objects / 对象**: Types $A, B, C, \ldots$
- **Morphisms / 态射**: Type-preserving functions $f: A \to B$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Type Safety)

Type systems ensure safety:

$$\text{well-typed}(P) \Rightarrow \text{safe}(P)$$

**Property 4.2** (Type Preservation)

Types are preserved:

$$f: A \to B \Rightarrow \text{type}(f) = A \to B$$

## 6. Examples / 例子

### 6.1 Simple Type Example / 简单类型例子

**Example 6.1** (Integer Type)

Consider integer type:

$$Type(1) = Int, Type(2) = Int$$

assigning integer type to integers.

### 6.2 Function Type Example / 函数类型例子

**Example 6.2** (Function Type)

Consider function type:

$$Type(\lambda x. x + 1) = Int \to Int$$

assigning function type.

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Label" Metaphor)

Types are like labels:

- **Labels / 标签**: Type labels
- **Classification / 分类**: Classifying values
- **Safety / 安全**: Ensuring correctness
- **Checking / 检查**: Verifying types

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Label 配例)

按 7.1「Label」比喻：类型如标签、分类值、确保正确性、通过检查验证。例如 $Type(1)=Int$、$Type(\lambda x. x+1)=Int \to Int$：标签对应类型分配，$Type: \mathbf{Term} \to \mathbf{Type}$ 为检查提供依据，与 7.1 四要素（标签、分类、安全、检查）一一对应。

## 8. Argumentation / 论证

### 8.1 Why Type Systems Exist / 为什么类型系统存在

**Argument 8.1** (Safety Argument)

Type systems exist because:

1. Programs need safety
2. Safety requires types
3. Types prevent errors
4. Errors cause failures
