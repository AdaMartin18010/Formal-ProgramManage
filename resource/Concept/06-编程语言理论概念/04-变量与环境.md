## 2. Definition / 定义

### 2.1 Harper Definition / Harper 定义

**Definition 2.1** (Environment - Harper)

An environment is a finite mapping from variables to types:

$$\Gamma = \{x_1: A_1, \ldots, x_n: A_n\}$$

**Environment Operations / 环境操作**:

- **Extension / 扩展**: $\Gamma, x: A$ - add variable
- **Lookup / 查找**: $\Gamma(x)$ - lookup variable type
- **Restriction / 限制**: $\Gamma \setminus x$ - remove variable

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Environment - Formal Definition)

An environment is a function:

$$\Gamma: \mathbf{Var} \to \mathbf{Type}$$

mapping variables to types.

---

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Environment as Object / 环境作为对象

**Definition 3.1** (Environment Object)

An environment $\Gamma \in \mathbf{Env}$ is an object:

$$\Gamma = \{x_1: A_1, \ldots, x_n: A_n\}$$

### 3.2 Environment Functor / 环境函子

**Definition 3.2** (Environment Functor)

The environment functor $Env: \mathbf{Type} \to \mathbf{Env}$:

$$Env(A) = \{\Gamma \mid \Gamma: \mathbf{Var} \to \mathbf{Type}\}$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Environment Extension)

Environments can be extended:

$$\Gamma, x: A \in \mathbf{Env} \text{ if } x \notin \text{dom}(\Gamma)$$

**Property 4.2** (Environment Lookup)

Variable lookup is defined:

$$\Gamma(x) = A \text{ if } x: A \in \Gamma$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Dictionary" Metaphor)

Environments are like dictionaries:

- **Entries / 条目**: Variable-type pairs
- **Lookup / 查找**: Finding variable types
- **Extension / 扩展**: Adding new entries
- **Context / 上下文**: Program context

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Dictionary 配例)

按 7.1「Dictionary」比喻：条目如 $\Gamma, x: A$ 的变量-类型对、查找如 $\Gamma(x)$、扩展与上下文如 $\Gamma, y: B$ 与作用域。例如 $\Gamma = \{x: Int, y: Bool\}$ 下 $Type(x+1)=Int$：$Environment: \mathbf{Type} \to \mathbf{Env}$ 与 7.1 的条目、查找、扩展、上下文一一对应。

## 8. Argumentation / 论证

### 8.1 Why Environments Exist / 为什么环境存在

**Argument 8.1** (Context Argument)

Environments exist because:

1. Programs need context
2. Context requires environments
3. Environments provide information
4. Information enables type checking
