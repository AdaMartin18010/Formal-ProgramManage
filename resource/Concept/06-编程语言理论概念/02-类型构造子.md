## 1. Overview / 概述

**English / 英文**:

Type constructors build complex types from simpler types. Common type constructors include product types, sum types, function types, list types, and maybe types. This document provides comprehensive coverage of type constructors from multiple perspectives.

**中文**:

类型构造子从简单类型构建复杂类型。常见的类型构造子包括积类型、和类型、函数类型、列表类型和可选类型。本文档从多个视角全面覆盖类型构造子。

**Key Insights / 关键洞察**:

- **Product Types / 积类型**: $A \times B$ - pairs / 对
- **Sum Types / 和类型**: $A + B$ - unions / 并集
- **Function Types / 函数类型**: $A \to B$ - functions / 函数
- **List Types / 列表类型**: $\text{List}(A)$ - sequences / 序列
- **Maybe Types / 可选类型**: $\text{Maybe}(A)$ - optional values / 可选值

## 2. Definition / 定义

### 2.1 Harper Definition / Harper 定义

**Definition 2.1** (Type Constructors - Harper)

Type constructors build types from types:

- **Product / 积**: $A \times B$ - pairs $(a, b)$
- **Sum / 和**: $A + B$ - either $A$ or $B$
- **Function / 函数**: $A \to B$ - functions from $A$ to $B$
- **List / 列表**: $\text{List}(A)$ - sequences of $A$
- **Maybe / 可选**: $\text{Maybe}(A)$ - optional $A$

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Type Constructor - Formal Definition)

A type constructor is a function:

$$Constructor: \mathbf{Type}^n \to \mathbf{Type}$$

building types from types.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Type Constructors as Functors / 类型构造子作为函子

**Definition 3.1** (Product Functor)

The product functor $\times: \mathbf{Type} \times \mathbf{Type} \to \mathbf{Type}$:

$$A \times B = \{(a, b) \mid a \in A, b \in B\}$$

### 3.2 Sum Functor / 和函子

**Definition 3.2** (Sum Functor)

The sum functor $+: \mathbf{Type} \times \mathbf{Type} \to \mathbf{Type}$:

$$A + B = \text{Left}(A) \cup \text{Right}(B)$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Product Associativity)

Products are associative:

$$(A \times B) \times C \cong A \times (B \times C)$$

**Property 4.2** (Sum Associativity)

Sums are associative:

$$(A + B) + C \cong A + (B + C)$$

## 6. Examples / 例子

### 6.1 Product Type Example / 积类型例子

**Example 6.1** (Pair Type)

Consider pair type:

$$Int \times String = \{(n, s) \mid n \in Int, s \in String\}$$

representing pairs of integers and strings.

### 6.2 Sum Type Example / 和类型例子

**Example 6.2** (Either Type)

Consider either type:

$$Int + String = \text{Left}(Int) \cup \text{Right}(String)$$

representing either integers or strings.

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Building Blocks" Metaphor)

Type constructors are like building blocks:

- **Blocks / 积木**: Basic types
- **Construction / 构建**: Building complex types
- **Combination / 组合**: Combining types
- **Structure / 结构**: Type structure

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Building Blocks 配例)

按 7.1「Building Blocks」比喻：基本类型如积木、积/和/函数等构造子如拼装与组合、复合类型如整体结构。例如 $\text{Maybe}(Int)=Int+\{\bot\}$、$\text{List}(A)$：从 $A$、$B$ 经 $\times$、$+$、$\to$ 等「积木」构建 $A\times B$、$A\to B$，对应 $ProjectPattern: \mathbf{Type} \to \mathbf{ProjectPattern}$ 在 PM 中的结构类比。

## 8. Argumentation / 论证

### 8.1 Why Type Constructors Exist / 为什么类型构造子存在

**Argument 8.1** (Composition Argument)

Type constructors exist because:

1. Types need composition
2. Composition requires constructors
3. Constructors build types
4. Types enable programs
