## 2. Definition / 定义

### 2.1 Type Class Definition / 类型类定义

**Definition 2.1** (Type Class)

A type class defines operations for types:

- **Functor / 函子**: $fmap: (a \to b) \to f a \to f b$
- **Applicative / 应用函子**: $pure: a \to f a$, $<*>: f (a \to b) \to f a \to f b$
- **Monad / 单子**: $return: a \to m a$, $>>=: m a \to (a \to m b) \to m b$

### 2.2 Monad Definition / 单子定义

**Definition 2.2** (Monad)

A monad is a triple $(M, return, >>=)$ satisfying:

- **Left Identity / 左恒等**: $return a >>= f = f a$
- **Right Identity / 右恒等**: $m >>= return = m$
- **Associativity / 结合性**: $(m >>= f) >>= g = m >>= (\lambda x. f x >>= g)$

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Monad as Endofunctor / 单子作为自函子

**Definition 3.1** (Monad)

A monad is an endofunctor $M: \mathbf{C} \to \mathbf{C}$ with:

- **Unit / 单位**: $\eta: \text{id} \Rightarrow M$
- **Multiplication / 乘法**: $\mu: M \circ M \Rightarrow M$

satisfying monad laws.

### 3.2 Monad Laws / 单子定律

**Axiom 3.1** (Monad Laws)

Monads satisfy:

- **Left Identity / 左恒等**: $\mu \circ (\eta \circ M) = \text{id}_M$
- **Right Identity / 右恒等**: $\mu \circ (M \circ \eta) = \text{id}_M$
- **Associativity / 结合性**: $\mu \circ (M \circ \mu) = \mu \circ (\mu \circ M)$

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Monad Composition)

Monads compose:

$$(M \circ N)(A) = M(N(A))$$

**Property 4.2** (Monad Functor)

Monads are functors:

$$M: \mathbf{C} \to \mathbf{C}$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Container" Metaphor)

Monads are like containers:

- **Container / 容器**: Wrapping values
- **Operations / 操作**: Transforming contents
- **Composition / 复合**: Chaining operations
- **Effects / 效果**: Handling effects

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Container 配例)

按 7.1「Container」比喻：单子如容器包裹值、return/>>= 如装入与链式操作、复合与效果如组合与副作用处理。例如 $return: a \to m a$、$>>=: m a \to (a \to m b) \to m b$：$\mu \circ (M \circ \eta)=\text{id}_M$ 等定律保证「装—取—再装」的语义一致，与 7.1 的容器、操作、复合、效果四要素对应。

## 8. Argumentation / 论证

### 8.1 Why Monads Exist / 为什么单子存在

**Argument 8.1** (Structure Argument)

Monads exist because:

1. Computations need structure
2. Structure requires monads
3. Monads enable composition
4. Composition enables programs
