## 1. Overview / 概述

**English / 英文**:

Execution flow represents how programs execute step by step, and semantics defines the meaning of programs. This document provides comprehensive coverage of execution flow and semantics from multiple perspectives.

**中文**:

执行流表示程序如何逐步执行，语义定义程序的含义。本文档从多个视角全面覆盖执行流和语义。

**Key Insights / 关键洞察**:

- **Execution States / 执行状态**: $S \in \mathbf{Exec}$ - execution states / 执行状态
- **Execution Steps / 执行步骤**: $S_i \to S_j$ - step transitions / 步骤转换
- **Operational Semantics / 操作语义**: $\langle e, \sigma \rangle \Downarrow v$ / 操作语义
- **Denotational Semantics / 指称语义**: $\llbracket e \rrbracket: \mathbf{Env} \to \mathbf{Val}$ / 指称语义
- **Axiomatic Semantics / 公理语义**: $\{P\} e \{Q\}$ / 公理语义

## 2. Definition / 定义

### 2.1 Plotkin Definition / Plotkin 定义

**Definition 2.1** (Operational Semantics - Plotkin)

Operational semantics defines execution steps:

- **Big-Step Semantics / 大步语义**: $\langle e, \sigma \rangle \Downarrow v$
- **Small-Step Semantics / 小步语义**: $e \to e'$

### 2.2 Stoy Definition / Stoy 定义

**Definition 2.2** (Denotational Semantics - Stoy)

Denotational semantics assigns meanings:

$$\llbracket e \rrbracket: \mathbf{Env} \to \mathbf{Val}$$

### 2.3 Hoare Definition / Hoare 定义

**Definition 2.3** (Axiomatic Semantics - Hoare)

Axiomatic semantics uses Hoare triples:

$$\{P\} e \{Q\}$$

---

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Execution as Category / 执行作为范畴

**Definition 3.1** (Category $\mathbf{Exec}$)

The category $\mathbf{Exec}$ consists of:

- **Objects / 对象**: Execution states $S \in \mathbf{Exec}$
- **Morphisms / 态射**: Execution steps $step: S_i \to S_j$

### 3.2 Execution Functor / 执行函子

**Definition 3.2** (Execution Functor)

The execution functor $Exec: \mathbf{Program} \to \mathbf{Exec}$:

$$Exec(P) = (States, Steps, Initial, Final)$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Execution Determinism)

Execution is deterministic:

$$\forall S_i, \exists! S_j: step(S_i) = S_j$$

**Property 4.2** (Execution Termination)

Execution terminates:

$$\exists S_{final}: \text{no step from } S_{final}$$

## 6. Examples / 例子

### 6.1 Operational Semantics Example / 操作语义例子

**Example 6.1** (Expression Evaluation)

Consider expression evaluation:

$$\langle 1 + 2, \sigma \rangle \Downarrow 3$$

representing big-step execution.

### 6.2 Denotational Semantics Example / 指称语义例子

**Example 6.2** (Expression Meaning)

Consider expression meaning:

$$\llbracket 1 + 2 \rrbracket(\sigma) = 3$$

assigning meaning to expression.

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Recipe" Metaphor)

Execution is like following a recipe:

- **Steps / 步骤**: Execution steps
- **Ingredients / 成分**: Program state
- **Result / 结果**: Final value
- **Meaning / 含义**: Recipe interpretation

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Recipe 配例)

按 7.1「Recipe」比喻：步骤如 $step: S_i \to S_j$、成分为程序状态、结果为 $\langle e,\sigma\rangle \Downarrow v$、含义如 $\llbracket e \rrbracket: \mathbf{Env} \to \mathbf{Val}$。例如操作语义与指称语义：大步/小步与 7.1 的步骤—成分—结果—含义对应，$Execution: \mathbf{CFG} \to \mathbf{Exec}$ 体现执行流到语义的映射。
