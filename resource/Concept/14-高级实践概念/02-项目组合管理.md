## 2. Definition / 定义

### 2.1 Portfolio Management Definition / 组合管理定义

**Definition 2.1** (Project Portfolio Management)

Project portfolio management is:

$$PortfolioManagement: \mathbf{Projects} \to \mathbf{Portfolio}$$

managing project collections.

### 2.2 PMBOK 8th Edition Definition / PMBOK 第8版定义

**Definition 2.2** (Portfolio Management - PMBOK 8th Edition)

Portfolio management is the centralized management of one or more portfolios to achieve strategic objectives, aligned with PMBOK 8th Edition focus on value delivery and strategic alignment.

**Portfolio Components / 组合组件**:

- **Portfolio Selection / 组合选择**: Selecting projects
- **Portfolio Optimization / 组合优化**: Optimizing portfolios
- **Strategic Alignment / 战略对齐**: Aligning with strategy
- **Value Delivery / 价值交付**: Delivering value (PMBOK 8th emphasis)

### 2.3 ISO 21504:2015 Definition / ISO 21504:2015定义

**Definition 2.3** (Portfolio Management - ISO 21504:2015)

ISO 21504:2015 provides guidance on portfolio management, applicable to any organization managing portfolios of projects, programmes, and other work to achieve strategic objectives.

**Formal Definition / 形式化定义**:

$$\text{PortfolioManagement}_{ISO21504} = (\text{Selection}, \text{Optimization}, \text{Alignment}, \text{Governance})$$

where:

- $\text{Selection}$: Portfolio selection practices
- $\text{Optimization}$: Portfolio optimization practices
- $\text{Alignment}$: Strategic alignment practices
- $\text{Governance}$: Portfolio governance practices

**Key Practices / 关键实践**:

1. **Portfolio Selection / 组合选择**: Select projects and programmes
2. **Portfolio Optimization / 组合优化**: Optimize portfolio composition
3. **Strategic Alignment / 战略对齐**: Align with organizational strategy
4. **Resource Allocation / 资源分配**: Allocate resources across portfolio
5. **Performance Management / 绩效管理**: Manage portfolio performance
6. **Governance / 治理**: Portfolio governance

### 8.1 Why Portfolio Management Exists / 为什么组合管理存在

3. Selection requires management
4. Management enables strategy
