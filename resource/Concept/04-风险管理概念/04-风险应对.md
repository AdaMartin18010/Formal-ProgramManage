## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Risk Response - PMBOK 7th Edition)

Risk response develops options and actions to enhance opportunities and reduce threats to project objectives.

**Response Strategies / 应对策略**:

- **Avoid / 规避**: Eliminating the threat
- **Mitigate / 减轻**: Reducing probability or impact
- **Transfer / 转移**: Shifting risk to third party
- **Accept / 接受**: Acknowledging the risk

### 2.2 ISO 31000 Standard Definition / ISO 31000 标准定义

**Definition 2.2** (Risk Treatment - ISO 31000:2018)

Risk treatment modifies risk through risk response options.

### 2.3 Formal Mathematical Definition / 形式化数学定义

**Definition 2.3** (Risk Response - Formal Definition)

Risk response is a function:

$$respond: \mathbf{Risk} \to \mathbf{Response}$$

where $Response \in \{Avoid, Mitigate, Transfer, Accept\}$.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Response as Morphism / 应对作为态射

**Definition 3.1** (Risk Response Morphism)

A risk response morphism $respond: \mathbf{Risk} \to \mathbf{Response}$:

$$respond(Risk) = Response$$

### 3.2 Response Properties / 应对性质

**Property 3.1** (Response Effectiveness)

Risk responses are effective:

$$respond(Risk) \Rightarrow \text{risk exposure reduced}$$

## 6. Examples / 例子

### 6.1 Mitigation Example / 减轻例子

**Example 6.1** (Risk Mitigation)

Consider risk mitigation:

$$respond(Risk_{tech}) = Mitigate(\text{prototype testing})$$

### 6.2 Transfer Example / 转移例子

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Shield" Metaphor)

Risk response is like a shield:

- **Protection / 保护**: Shielding from risks
- **Strategies / 策略**: Different shield types
- **Effectiveness / 有效性**: Shield strength
- **Appropriateness / 适当性**: Right shield for risk

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (应对即盾牌 + 一例 / Response as Shield with One Example)

用「盾牌」比喻：保护=减损、策略=缓解/转移/接受/规避、有效性=降概率或降影响、适当性=对症。例如 $respond(Risk_{tech})=Mitigate(\text{prototype testing})$ 即用原型测试缓解技术风险；$respond(Risk_{financial})=Transfer(\text{insurance})$ 即用保险转移财务风险。

## 8. Argumentation / 论证

### 8.1 Why Response Exists / 为什么应对存在

**Argument 8.1** (Action Argument)

Response exists because:

1. Risks need action
2. Action requires response
3. Response reduces exposure
4. Exposure reduction enables success
