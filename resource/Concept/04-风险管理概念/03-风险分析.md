## 1. Overview / 概述

**English / 英文**:

Risk analysis evaluates identified risks by assessing their probability and impact. This document provides comprehensive coverage of risk analysis from multiple perspectives.

**中文**:

风险分析通过评估概率和影响来评估已识别的风险。本文档从多个视角全面覆盖风险分析。

**Key Insights / 关键洞察**:

- **Risk Analysis Function / 风险分析函数**: $analyze: Risk \to RiskAnalysis$ / 风险分析函数
- **Probability Assessment / 概率评估**: Assessing risk probability / 评估风险概率
- **Impact Assessment / 影响评估**: Assessing risk impact / 评估风险影响
- **Risk Exposure / 风险暴露**: $Exposure = Probability \times Impact$ / 风险暴露

## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Risk Analysis - PMBOK 7th Edition)

Risk analysis evaluates identified risks by assessing their probability and impact.

**Analysis Types / 分析类型**:

- **Qualitative Analysis / 定性分析**: Assessing probability and impact qualitatively
- **Quantitative Analysis / 定量分析**: Assessing probability and impact quantitatively
- **Risk Exposure / 风险暴露**: Calculating risk exposure

### 2.2 ISO 31000 Standard Definition / ISO 31000 标准定义

**Definition 2.2** (Risk Analysis - ISO 31000:2018)

Risk analysis understands the nature of risk and determines the level of risk.

### 2.3 Formal Mathematical Definition / 形式化数学定义

**Definition 2.3** (Risk Analysis - Formal Definition)

Risk analysis is a function:

$$analyze: \mathbf{Risk} \to \mathbf{RiskAnalysis}$$

where:

$$analyze(Risk) = (Probability, Impact, Exposure)$$

and $Exposure = Probability \times Impact$.

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Weather Forecast" Metaphor)

Risk analysis is like weather forecast:

- **Probability / 概率**: Forecast probability
- **Impact / 影响**: Weather severity
- **Exposure / 暴露**: Risk level
- **Assessment / 评估**: Forecast evaluation

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (分析即预报评估 + 一例 / Analysis as Forecast Evaluation with One Example)

用「预报评估」比喻：概率=发生可能、影响=严重度、暴露=概率×影响、评估=等级。例如 $analyze(Risk_{tech})=(High, High, High)$ 即高概率高影响；$analyze(Risk_{schedule})=(0.5, 10, 5)$ 即 50% 概率、影响 10、暴露 5。
