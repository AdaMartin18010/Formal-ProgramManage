# Concept 概念目录

## 概述

本目录从**概念分析论证**视角组织 **Formal-ProgramManage** 项目的项目管理概念，与 `docs/` 主线的**层次结构（层）**和**转换关系**严格对齐。

## 与 docs 的对应：层与转换

### 理论层次（层）

| 层 | docs 对应 | resource/Concept 对应 |
|:---|:---|:---|
| **基础理论层** | 01-foundations（数学、逻辑、语义） | 01-项目管理基础（形式化定义、状态空间、约束） |
| **核心模型层** | 02-project-management | 02-生命周期、03-资源管理、04-风险管理、05-质量管理 |
| **验证理论层** | 03-formal-verification, 06-ci-verification | 07-程序分析概念（静态/动态分析） |
| **应用模型层** | 04-industry-applications | 08-行业应用概念 |
| **实现验证层** | 05-implementations, 06-ci-verification | 10-Transfer概念、12-Transfer应用、13-综合实践、14-高级实践 |

### 转换关系

- **生命周期转换**：`docs/02-project-management/lifecycle-models.md` 中的 $\delta: S \times \Sigma \rightarrow S$、转换点 $T$ → Concept **02-生命周期概念**（启动→规划→执行→监控→收尾）
- **状态转换**：`docs/01-foundations` 的 Kripke 结构、语义模型中的 $\rightarrow \subseteq S \times S$ → Concept **01-项目管理基础/03-项目状态空间**、**09-高级概念/02-项目变换类型**
- **层次转换**：`docs/KNOWLEDGE_NETWORK.md` 的 L1→L2→L3→L4→L5 → Concept **09-高级概念**、**10-Transfer概念**、**12-Transfer应用**（等价、变换类型、变换关系网络）
- **模型转换**：`docs/06-ci-verification` 的模型检验、一致性检查 → **07-程序分析**、**10–12 Transfer 概念/应用**
