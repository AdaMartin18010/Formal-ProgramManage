## 2. Definition / 定义

### 2.1 Application Definition / 应用定义

**Definition 2.1** (Project Equivalence Application)

Project equivalence applications use equivalence relations:

$$EquivApp: \mathbf{Project} \times \mathbf{Equiv} \to \mathbf{Classification}$$

classifying projects by equivalence.

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Equivalence Application - Formal Definition)

An equivalence application is a function:

$$EquivApp(P, \sim) = [P]_{\sim}$$

where $[P]_{\sim}$ is the equivalence class of $P$.

---

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Application as Functor / 应用作为函子

**Definition 3.1** (Equivalence Application Functor)

Equivalence application is a functor:

$$EquivApp: \mathbf{Project} \times \mathbf{Equiv} \to \mathbf{Classification}$$

classifying projects.

### 3.2 Application Properties / 应用性质

**Axiom 3.1** (Equivalence Application Functoriality)

Equivalence application preserves composition:

$$EquivApp(f \circ g, \sim) = EquivApp(f, \sim) \circ EquivApp(g, \sim)$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Equivalence Classification)

Equivalence applications classify projects:

$$\forall P: EquivApp(P, \sim) = [P]_{\sim}$$

**Property 4.2** (Equivalence Consistency)

Equivalence applications are consistent:

$$\forall P_1, P_2: P_1 \sim P_2 \Rightarrow EquivApp(P_1, \sim) = EquivApp(P_2, \sim)$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Grouping" Metaphor)

Equivalence applications are like grouping:

- **Classification / 分类**: Grouping similar projects / 分组相似项目
- **Comparison / 比较**: Comparing project groups / 比较项目组
- **Pattern Recognition / 模式识别**: Recognizing patterns / 识别模式

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Grouping 配例)

按 7.1「Grouping」比喻：分类如 $[P]=\{Q \mid P \sim Q\}$、比较如跨等价类的指标对比、模式识别如 $\sim_S$、$\sim_B$ 下的共性。例如等价关系应用将项目分组成 $[P]$ 后做 Portfolio 决策，与 7.1 的分类—比较—模式识别对应。
