## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Project Initiation - PMBOK 7th Edition)

Project initiation is the process of formally authorizing a new project or a new phase of an existing project.

**Key Activities / 关键活动**:

- **Project Charter / 项目章程**: Creating project charter
- **Stakeholder Identification / 利益相关者识别**: Identifying stakeholders
- **Initial Requirements / 初始需求**: Gathering initial requirements
- **Project Authorization / 项目授权**: Authorizing project

### 2.2 ISO 21500 Standard Definition / ISO 21500 标准定义

**Definition 2.2** (Project Initiation - ISO 21500:2012)

Project initiation establishes the project and defines its initial scope.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Initiation as Object / 启动作为对象

**Definition 3.1** (Initiation Phase Object)

The initiation phase $Ph_{init} \in \mathbf{Phase}$ is an object:
$$Ph_{init} = (Name_{init}, State_{init}, Milestones_{init}, Deliverables_{init})$$

### 3.2 Initiation Morphisms / 启动态射

**Definition 3.2** (Initiation Transition Morphism)

The initiation-to-planning transition:
$$\tau_{init \to plan}: Ph_{init} \to Ph_{plan}$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Initiation Existence)

Every project has an initiation phase:
$$\forall P \in \mathbf{Project}: \exists Ph_{init} \in L(P)$$

**Property 4.2** (Initiation Uniqueness)

Each project has a unique initiation phase.

---

## 5. Relations / 关系

### 5.1 Relations to Other Concepts / 与其他概念的关系

**Relation 5.1** (Initiation → Planning)

Initiation precedes planning:
$$Ph_{init} \to Ph_{plan}$$

**Relation 5.2** (Initiation → Project)

Initiation is part of project:
$$Ph_{init} \in L(P)$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Starting a Journey" Metaphor)

Project initiation is like starting a journey:

- **Destination / 目的地**: Project goals
- **Preparation / 准备**: Initial planning
- **Authorization / 授权**: Permission to start
- **Team / 团队**: Project team formation

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (启动即出发前准备 + 一例 / Initiation as Pre-Departure with One Example)

用「出发前的准备」比喻：目的地=项目目标，准备=章程与初步范围，授权=立项批复，团队=核心成员到位。例如 $Ph_{init}$ 的交付物=项目章程+利益相关者登记册；$\tau_{init \to plan}$ 的触发条件=章程签署。

## 8. Argumentation / 论证

### 8.1 Why Initiation Exists / 为什么启动存在

**Argument 8.1** (Necessity Argument)

Initiation exists because:

1. Projects need authorization
2. Authorization requires initiation
3. Initiation provides foundation
4. Foundation enables success
