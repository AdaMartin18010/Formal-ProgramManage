## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Project Execution - PMBOK 7th Edition)

Project execution is the process of performing the work defined in the project management plan to achieve the project's objectives.

**Key Activities / 关键活动**:

- **Work Performance / 工作执行**: Performing project work
- **Team Management / 团队管理**: Managing project team
- **Communication / 沟通**: Communicating with stakeholders
- **Procurement / 采购**: Procuring resources
- **Quality Assurance / 质量保证**: Ensuring quality

### 2.2 ISO 21500 Standard Definition / ISO 21500 标准定义

**Definition 2.2** (Project Execution - ISO 21500:2012)

Project execution performs project work according to the plan.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Execution as Object / 执行作为对象

**Definition 3.1** (Execution Phase Object)

The execution phase $Ph_{exec} \in \mathbf{Phase}$ is an object:

$$Ph_{exec} = (Name_{exec}, State_{exec}, Milestones_{exec}, Deliverables_{exec})$$

### 3.2 Execution Morphisms / 执行态射

**Definition 3.2** (Execution Transition Morphism)

The execution-to-monitoring transition:

$$\tau_{exec \to mon}: Ph_{exec} \to Ph_{mon}$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Execution Existence)

Every project has an execution phase:

$$\forall P \in \mathbf{Project}: \exists Ph_{exec} \in L(P)$$

**Property 4.2** (Execution Progress)

Execution progresses:

$$\forall Task \in Plan: \exists ExecutionStep: Task \to ExecutionStep$$

---

## 5. Relations / 关系

### 5.1 Relations to Other Concepts / 与其他概念的关系

**Relation 5.1** (Execution → Planning)

Execution follows planning:

$$Ph_{plan} \to Ph_{exec}$$

**Relation 5.2** (Execution → Monitoring)

Execution is monitored:

$$Ph_{exec} \to Ph_{mon}$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Building" Metaphor)

Project execution is like building:

- **Blueprint / 蓝图**: Project plan
- **Construction / 建设**: Project work
- **Materials / 材料**: Project resources
- **Progress / 进度**: Project progress

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (执行即按图施工 + 一例 / Execution as Building to Blueprint with One Example)

用「按图施工」比喻：蓝图=计划，建设=开发/实施，材料=资源，进度=完成度。例如 $Ph_{exec}$ 中「开发」=写代码与单测、「集成」=持续集成与联调；$\tau_{exec \to monitor}$ 由迭代或阶段评审触发。

## 8. Argumentation / 论证

### 8.1 Why Execution Exists / 为什么执行存在

**Argument 8.1** (Necessity Argument)

Execution exists because:

1. Plans need implementation
2. Implementation requires execution
3. Execution produces results
4. Results achieve goals
