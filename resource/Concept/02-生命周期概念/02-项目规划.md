## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Project Planning - PMBOK 7th Edition)

Project planning is the process of establishing the scope, defining and refining objectives, and developing the course of action required to attain those objectives.

**Key Activities / 关键活动**:

- **Scope Planning / 范围规划**: Planning project scope
- **Schedule Planning / 进度规划**: Planning project schedule
- **Resource Planning / 资源规划**: Planning project resources
- **Risk Planning / 风险规划**: Planning project risks
- **Quality Planning / 质量规划**: Planning project quality

### 2.2 ISO 21500 Standard Definition / ISO 21500 标准定义

**Definition 2.2** (Project Planning - ISO 21500:2012)

Project planning establishes project plans and defines project activities.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Planning as Object / 规划作为对象

**Definition 3.1** (Planning Phase Object)

The planning phase $Ph_{plan} \in \mathbf{Phase}$ is an object:

$$Ph_{plan} = (Name_{plan}, State_{plan}, Milestones_{plan}, Deliverables_{plan})$$

### 3.2 Planning Morphisms / 规划态射

**Definition 3.2** (Planning Transition Morphism)

The planning-to-execution transition:

$$\tau_{plan \to exec}: Ph_{plan} \to Ph_{exec}$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Planning Existence)

Every project has a planning phase:

$$\forall P \in \mathbf{Project}: \exists Ph_{plan} \in L(P)$$

**Property 4.2** (Planning Completeness)

Planning covers all project aspects:

$$Plan(P) = (ScopePlan, SchedulePlan, ResourcePlan, RiskPlan, QualityPlan)$$

---

## 5. Relations / 关系

### 5.1 Relations to Other Concepts / 与其他概念的关系

**Relation 5.1** (Planning → Execution)

Planning precedes execution:

$$Ph_{plan} \to Ph_{exec}$$

**Relation 5.2** (Planning → Resources)

Planning uses resources:

$$Resource: \mathbf{Plan} \to \mathbf{Resource}$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Roadmap" Metaphor)

Project planning is like creating a roadmap:

- **Destination / 目的地**: Project goals
- **Route / 路线**: Project plan
- **Resources / 资源**: Fuel and supplies
- **Timeline / 时间线**: Travel schedule

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (规划即路线图 + 一例 / Planning as Roadmap with One Example)

用「路线图」比喻：目的地=目标，路线=WBS+甘特图，资源=预算与人力，时间线=里程碑。例如 $Ph_{plan}$ 的输出=范围说明书、进度基准、成本基准；$\tau_{plan \to exec}$ 的触发=基线获批。

## 8. Argumentation / 论证

### 8.1 Why Planning Exists / 为什么规划存在

**Argument 8.1** (Necessity Argument)

Planning exists because:

1. Projects need direction
2. Direction requires planning
3. Planning provides structure
4. Structure enables success
