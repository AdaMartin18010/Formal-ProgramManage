## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Resource Allocation - PMBOK 7th Edition)

Resource allocation is the process of assigning resources to project activities based on resource availability and project requirements.

**Key Activities / 关键活动**:

- **Resource Assignment / 资源分配**: Assigning resources to tasks
- **Capacity Planning / 容量规划**: Planning resource capacity
- **Conflict Resolution / 冲突解决**: Resolving allocation conflicts
- **Optimization / 优化**: Optimizing resource utilization

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Resource Allocation - Formal Definition)

Resource allocation is a function:

$$alloc: Task \times Resource \to Allocation$$

where $Allocation = (Task, Resource, Amount, Schedule)$.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Allocation as Morphism / 分配作为态射

**Definition 3.1** (Resource Allocation Morphism)

A resource allocation morphism $alloc: Task \times Resource \to Allocation$:

$$alloc(T, Res) = Alloc$$

### 3.2 Allocation Properties / 分配性质

**Property 3.1** (Allocation Constraints)

Allocations respect constraints:

$$alloc(T, Res) \Rightarrow Capacity(Res) \geq Amount(Alloc)$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Allocation Feasibility)

Allocations are feasible:

$$\forall Alloc: Feasible(Alloc) \Rightarrow Valid(Alloc)$$

**Property 4.2** (Allocation Completeness)

Allocations cover all tasks:

$$\forall T \in Tasks: \exists Alloc: Task(Alloc) = T$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Assignment" Metaphor)

Resource allocation is like assignment:

- **Tasks / 任务**: Work to be done
- **Resources / 资源**: Tools and people
- **Assignment / 分配**: Matching resources to tasks
- **Optimization / 优化**: Best matching

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (分配即派活 + 一例 / Allocation as Assignment with One Example)

用「派活」比喻：任务=待办、资源=人与设备、分配=谁做哪件、优化=最佳匹配。例如 $alloc(Task_{dev}, Dev_{team})=Alloc_{dev}$ 即开发任务派给开发组；$alloc(Task_{deploy}, Server_{pool})=Alloc_{server}$ 即部署任务派给服务器池。

## 8. Argumentation / 论证

### 8.1 Why Allocation Exists / 为什么分配存在

**Argument 8.1** (Necessity Argument)

Allocation exists because:

1. Tasks need resources
2. Resources need assignment
3. Assignment requires allocation
4. Allocation enables work
