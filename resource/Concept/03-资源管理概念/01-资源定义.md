## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Resource - PMBOK 7th Edition)

Resources are assets required to complete project work, including:

- **Human Resources / 人力资源**: People with skills and expertise
- **Material Resources / 物质资源**: Materials and supplies
- **Equipment / 设备**: Tools and equipment
- **Financial Resources / 财务资源**: Budget and funding

### 2.2 ISO 21500 Standard Definition / ISO 21500 标准定义

**Definition 2.2** (Resource - ISO 21500:2012)

Resources are assets required to perform project activities.

### 2.3 Formal Mathematical Definition / 形式化数学定义

**Definition 2.3** (Resource - Formal Definition)

A resource is a tuple:

$$Res = (Type, Capacity, Availability, Cost)$$

where:

- $Type$ is the resource type
- $Capacity$ is the resource capacity
- $Availability$ is the availability schedule
- $Cost$ is the resource cost

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Resource as Object / 资源作为对象

**Definition 3.1** (Resource Object)

A resource $Res \in \mathbf{Resource}$ is an object:

$$Res = (Type, Capacity, Availability, Cost)$$

### 3.2 Resource Morphisms / 资源态射

**Definition 3.2** (Resource Allocation Morphism)

A resource allocation morphism $alloc: Project \times Resource \to Allocation$:

$$alloc(P, Res) = Alloc$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Resource Existence)

Resources exist:

$$\forall P \in \mathbf{Project}: \exists Res \in R(P)$$

**Property 4.2** (Resource Capacity)

Resources have capacity:

$$\forall Res: Capacity(Res) \geq 0$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Toolbox" Metaphor)

Resources are like a toolbox:

- **Tools / 工具**: Different resource types
- **Capacity / 容量**: Tool availability
- **Usage / 使用**: Resource allocation
- **Cost / 成本**: Tool cost

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (资源即工具箱 + 一例 / Resources as Toolbox with One Example)

用「工具箱」比喻：工具=资源类型，容量=可用量，使用=分配，成本=占用。例如 $Res=(Human, 5, Schedule, Cost)$ 即 5 人、可用时段与人工费率；$Res=(Equipment, 10, \ldots)$ 即 10 台设备及档期与租赁费。

## 8. Argumentation / 论证

### 8.1 Why Resources Exist / 为什么资源存在

**Argument 8.1** (Necessity Argument)

Resources exist because:

1. Projects need assets
2. Assets are resources
3. Resources enable work
4. Work achieves goals
