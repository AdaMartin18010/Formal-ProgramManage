## 2. Definition / 定义

### 2.1 Network Definition / 网络定义

**Definition 2.1** (Project Transformation Network)

A project transformation network $G = (P, T)$ consists of:

- **Nodes / 节点**: Projects $P = \{P_1, P_2, \ldots, P_n\}$
- **Edges / 边**: Transformations $T = \{T_1, T_2, \ldots, T_m\}$ where $T_i: P_j \to P_k$

### 2.2 Formal Mathematical Definition / 形式化数学定义

**Definition 2.2** (Transformation Network - Formal Definition)

A transformation network is a directed graph:

$$G = (P, T)$$

where:

- $P$ is the set of project nodes
- $T \subseteq P \times P$ is the set of transformation edges

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Network as Category / 网络作为范畴

**Definition 3.1** (Transformation Network Category)

The transformation network category $\mathbf{TransNet}$ consists of:

- **Objects / 对象**: Projects $P \in \mathbf{Project}$
- **Morphisms / 态射**: Transformations $T: P_1 \to P_2$

### 3.2 Network Properties / 网络性质

**Axiom 3.1** (Network Category Axioms)

The network category satisfies category axioms:

- **Composition / 复合**: $(T_2 \circ T_1): P_1 \to P_3$
- **Identity / 恒等**: $\text{id}_P: P \to P$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Network Connectivity)

Transformation networks are connected:

$$\forall P_i, P_j: \exists \text{path from } P_i \text{ to } P_j$$

**Property 4.2** (Network Composition)

Transformations compose in networks:

$$(T_3 \circ T_2) \circ T_1 = T_3 \circ (T_2 \circ T_1)$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Transformation Web" Metaphor)

Transformation networks are like transformation webs:

- **Nodes / 节点**: Projects / 项目
- **Edges / 边**: Transformations / 变换
- **Paths / 路径**: Transformation paths / 变换路径
- **Cycles / 循环**: Transformation cycles / 变换循环

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (Transformation Web 配例)

按 7.1「Transformation Web」比喻：节点如 $G=(V,E)$ 中项目、边如变换态射、路径如 $Path(P_1,P_n)$、循环如 $T \circ T \circ \cdots = id$ 的周期。例如 $PathFramework=\{Path, Sequence, Parallel, Optimize\}$ 下，从 $P_0$ 到 $P_n$ 的路径与 7.1 的节点—边—路径—循环四要素对应。
