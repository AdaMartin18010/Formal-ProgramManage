## 0. 所属层与转换关系 / Layer and Transformation

- **所属层**：**核心模型层**（对应 docs/02-project-management）
- **转换关系**：**质量控制**是质量管理的**控制转换**，对应质量状态空间的控制操作 $control: QualityAssurance \to QualityControl$；与生命周期转换（02）协同，在项目执行/监控阶段进行质量控制转换。

## 1. Overview / 概述

**English / 英文**:

Quality control monitors and records results of quality activities to assess performance and recommend necessary changes. This document provides comprehensive coverage of quality control from multiple perspectives.

**中文**:

质量控制监控和记录质量活动的结果，以评估绩效并建议必要的更改。本文档从多个视角全面覆盖质量控制。

**Key Insights / 关键洞察**:

- **Quality Control Function / 质量控制函数**: $control: QualityExecution \to QualityControl$ / 质量控制函数
- **Quality Measurement / 质量测量**: Measuring quality attributes / 测量质量属性
- **Quality Monitoring / 质量监控**: Monitoring quality levels / 监控质量水平
- **Quality Correction / 质量纠正**: Correcting quality issues / 纠正质量问题

## 2. Definition / 定义

### 2.1 PMBOK 7th Edition Definition / PMBOK 第7版定义

**Definition 2.1** (Quality Control - PMBOK 7th Edition)

Quality control monitors and records results of quality activities to assess performance and recommend necessary changes.

**Key Activities / 关键活动**:

- **Quality Measurement / 质量测量**: Measuring quality attributes
- **Quality Monitoring / 质量监控**: Monitoring quality levels
- **Quality Inspection / 质量检查**: Inspecting deliverables
- **Quality Correction / 质量纠正**: Correcting quality issues

### 2.2 ISO 9001 Standard Definition / ISO 9001 标准定义

**Definition 2.2** (Quality Control - ISO 9001:2015)

Quality control ensures that quality requirements are met.

### 2.3 Formal Mathematical Definition / 形式化数学定义

**Definition 2.3** (Quality Control - Formal Definition)

Quality control is a function:

$$control: \mathbf{QualityExecution} \to \mathbf{QualityControl}$$

monitoring and controlling quality.

## 3. Category Theory Perspective / 范畴论视角

### 3.1 Control as Morphism / 控制作为态射

**Definition 3.1** (Quality Control Morphism)

A quality control morphism $control: \mathbf{QualityExecution} \to \mathbf{QualityControl}$:

$$control(QualityExecution) = QualityControl$$

### 3.2 Control Properties / 控制性质

**Property 3.1** (Control Effectiveness)

Quality control is effective:

$$control(QualityExecution) \Rightarrow \text{quality maintained}$$

---

## 4. Properties / 性质

### 4.1 Basic Properties / 基本性质

**Property 4.1** (Control Effectiveness)

Quality control is effective:

$$control(QualityExecution) \Rightarrow \text{quality maintained}$$

**Property 4.2** (Control Continuity)

Quality control is continuous:

$$\forall t: \exists control_t: QualityExecution \to QualityControl$$

## 7. Explanations / 解释

### 7.1 Intuitive Explanation / 直观解释

**Explanation 7.1** ("Thermostat" Metaphor)

Quality control is like a thermostat:

- **Measurement / 测量**: Temperature reading
- **Monitoring / 监控**: Continuous monitoring
- **Control / 控制**: Adjusting temperature
- **Maintenance / 维护**: Maintaining quality

### 7.3 直观解释配例 / Intuitive Explanation with One Example

**Example 7.3** (质量控制即温控 + 一例 / Control as Thermostat with One Example)

用「温控器」比喻：测量=读数、监控=持续监测、控制=调温（纠偏）、维护=维持质量。例如 $control(QualityExecution_{perf})=QualityControl_{perf}$ 测性能并纠偏；$control(QualityExecution_{deliverable})=QualityControl_{deliverable}$ 对交付物做检验与返工决策。

## 8. Argumentation / 论证

### 8.1 Why Control Exists / 为什么控制存在

**Argument 8.1** (Maintenance Argument)

Control exists because:

1. Quality needs maintenance
2. Maintenance requires control
3. Control ensures quality
4. Quality enables success
