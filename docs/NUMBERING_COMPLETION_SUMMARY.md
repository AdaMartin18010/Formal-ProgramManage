1. **章节编号**: 使用 `replace_all=True` 批量替换 `## 4.2.X.X` → `## 4.X.X`
2. **子章节编号**: 批量替换 `### 4.2.X.X` → `### 4.X.X`
3. **定义编号**: 批量替换 `**定义 4.2.X.X` → `**定义 4.X.X`
4. **定理编号**: 批量替换 `**定理 4.2.X.X` → `**定理 4.X.X`
