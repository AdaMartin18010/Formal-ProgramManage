# 术语表索引 / Glossary Index（单一权威入口）

**单一权威术语表**：本项目中，术语的权威定义与中英对照以 **[术语表 (Glossary)](../templates_and_standards/术语表-Glossary.md)** 为准。所有文档引用术语时，应指向本索引（[GLOSSARY.md](./GLOSSARY.md)）或术语表全文对应章节，避免在正文中重复定义造成不一致。

**术语表全文**：[术语表 (Glossary)](../templates_and_standards/术语表-Glossary.md) — 项目管理与形式化方法的中英术语、标准来源及备注。

**文档中引用约定**：核心概念首次出现时，可链接至本索引或直接链接至术语表对应章节，例如：

- 项目、项目管理、项目生命周期 → 术语表 §2 项目管理基础、§3 生命周期与过程
- Kripke 结构、LTL、CTL、模型检验、定理证明 → 术语表 §6 形式化方法术语
- 资源、风险、质量 → 术语表 §4、§5

**维护**：新增或变更术语时，仅更新 [术语表全文](../templates_and_standards/术语表-Glossary.md)；本索引保持为入口与映射。季度审查时检查术语表与各文档交叉引用一致性（见 [SUSTAINABLE_EXECUTION_PLAN.md](./SUSTAINABLE_EXECUTION_PLAN.md) 审查与更新节）。
